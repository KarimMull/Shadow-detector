# Camera YUV Shadow Detection

Программа для захвата видеопотока с USB-камеры в Windows, преобразования кадров в формат YUV, обнаружения теней с использованием классических методов компьютерного зрения, отображения результата в реальном времени и записи обработанного видео в MP4.

Проект написан на **C** и собирается в среде **MSYS2 UCRT64**.

---

## Возможности

* обнаружение доступных камер Windows через DirectShow;
* захват видео с камеры в реальном времени;
* поддержка формата камеры `YUYV422`;
* разрешение `640x480`;
* частота `30 FPS`;
* преобразование исходного изображения в `YUV420P`;
* построение адаптивного фонового изображения;
* обнаружение затемнённых областей относительно фона;
* анализ яркости канала Y;
* анализ цветовых компонентов U/V;
* адаптивные пороги U/V;
* морфологическая обработка маски:

  * открытие `3x3`;
  * закрытие `3x3`;
* фильтрация небольших областей по связанным компонентам;
* защита фона от обновления в областях обнаруженных теней;
* настройка чувствительности детектора;
* визуальное выделение обнаруженных теней;
* отображение видео через SDL2;
* запись результата в `MP4`.

# Построение фона

В начале работы программа собирает несколько кадров для построения фонового изображения.

Количество кадров по умолчанию:

```text
30
```

Фон хранится отдельно для каналов:

```text
Y
U
V
```

После накопления начального фона программа переходит к обычной обработке.

---

# Обнаружение тени

Для каждого пикселя рассчитывается отношение текущей яркости к яркости фона:

```text
Y_ratio = Y_current / Y_background
```

Затем определяется степень затемнения:

```text
darkness = 1 - Y_ratio
```

Область считается кандидатом на тень, если она достаточно темнее фонового изображения.

Основной критерий основан на относительном изменении яркости, а не только на фиксированном значении Y.

Это позволяет алгоритму работать при разных уровнях освещения лучше, чем простой порог:

```text
Y < constant
```

---

# Анализ цветности

Одного изменения яркости недостаточно, поскольку затемнение объекта или изменение освещения может быть ошибочно принято за тень.

Поэтому дополнительно анализируются:

```text
U
V
```

Компоненты текущего кадра сравниваются с компонентами фонового изображения.

Используются отдельные пороги:

```text
max_u_diff
max_v_diff
```

Также применяется адаптивная корректировка порогов в зависимости от степени затемнения.

---

# Морфологическая обработка

После определения первичной маски выполняются две операции.

## Opening

```text
Erosion
   ↓
Dilation
```

Открытие используется для удаления небольших шумовых областей.

Размер структурирующего элемента:

```text
3x3
```

---

## Closing

```text
Dilation
   ↓
Erosion
```

Закрытие используется для:

* заполнения небольших разрывов;
* объединения близких областей;
* улучшения формы обнаруженной тени.

Размер:

```text
3x3
```

---

# Связанные компоненты

После морфологической обработки выполняется поиск связанных областей.

Используется связность:

```text
4-connected
```

Для каждой области определяется её размер.

Слишком маленькие области удаляются как шум.

Минимальная площадь по умолчанию:

```text
100 pixels
```

Параметр:

```c
min_shadow_area
```

---

# Адаптивное обновление фона

Фоновое изображение не остаётся неизменным.

Для каждого пикселя используется экспоненциальное обновление:

```text
background =
    background * (1 - alpha) +
    current * alpha
```

По умолчанию:

```text
alpha = 0.01
```

Это позволяет фону медленно адаптироваться к изменению сцены.

---

# Защита фона от теней

Очень важная часть алгоритма — фон не должен обновляться на участках, которые в текущем кадре определены как тень.

Поэтому при обновлении:

```text
если pixel принадлежит тени
    фон НЕ обновляется
иначе
    фон обновляется
```

Это предотвращает постепенное "впитывание" тени в фон.

# Основные параметры

В `camera_yuv.c` используются следующие параметры:

```c
#define MIN_Y_SHADOW       0.25f
#define MAX_Y_SHADOW       0.75f
#define MAX_U              12
#define MAX_V              12
#define MIN_SHADOW_AREA    200
#define BACKGROUND_ALPHA  0.01f
```

### `MIN_Y_SHADOW`

Минимальная степень затемнения, необходимая для обнаружения тени.

Увеличение значения:

```text
меньше ложных срабатываний
```

но слишком большое значение может привести к пропуску слабых теней.

---

### `MAX_Y_SHADOW`

Максимальная допустимая степень затемнения.

Позволяет ограничить слишком тёмные области, которые скорее являются объектами, чем тенями.

---

### `MAX_U`

Допустимое изменение компоненты U.

Меньшее значение:

```text
строже проверка цвета
```

Большее:

```text
больше допустимых изменений цвета
```

---

### `MAX_V`

Аналогичный параметр для компоненты V.

---

### `MIN_SHADOW_AREA`

Минимальный размер области, которая считается настоящей тенью.

Например:

```text
100
```

означает, что области менее 100 пикселей удаляются.

---

### `BACKGROUND_ALPHA`

Скорость адаптации фоновой модели.

```text
0.01
```

означает медленное обновление.

Большое значение:

```text
0.05
0.10
```

позволяет быстрее адаптироваться к изменениям сцены, но повышает вероятность поглощения объектов фоном.

# Запуск

Запуск выполняется командой:

```bash
./camera_yuv.exe
```

После запуска программа:

1. обнаруживает камеру;
2. открывает видеопоток;
3. получает кадры;
4. строит первоначальный фон;
5. запускает обнаружение теней;
6. отображает результат;
7. записывает обработанное видео.

---

# Управление

Во время работы программы доступны клавиши:

| Клавиша | Действие                     |
| ------- | ---------------------------- |
| `Q`     | завершить программу          |
| `ESC`   | завершить программу          |
| `R`     | сбросить фоновое изображение |

Клавиша `R` полезна, если после запуска изменилась сцена.

Например:

```text
1. Запустили программу.
2. Построился фон.
3. Переместили камеру.
4. Нажали R.
5. Фон строится заново.
```

Обнаруженная тень выделяется поверх исходного изображения.

При разрешении:

```text
640x480
```

и:

```text
30 FPS
```

каждый кадр содержит:

```text

```

пикселей.

Основные операции выполняются непосредственно на CPU:

* сравнение Y;
* сравнение U/V;

Алгоритм не требует GPU и не использует нейронные сети.

# Ограничения алгоритма

Алгоритм предназначен для классического обнаружения теней и имеет ограничения.

На результат могут влиять:

* резкое изменение освещения;
* очень тёмные объекты;
* объекты, имеющие цвет, похожий на тень;
* резкое движение камеры;
* изменение положения камеры;
* блики;
* шум камеры;
* большие изменения сцены;
* очень медленное или слишком быстрое обновление фона.

Алгоритм не выполняет семантическое распознавание объектов.

То есть он определяет **область, похожую на тень**, а не устанавливает с помощью нейронной сети, что это действительно тень конкретного объекта.
