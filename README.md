# Camera YUV Shadow Detection

Программа для захвата видеопотока с USB-камеры в Windows, преобразования кадров в формат YUV, обнаружения теней с использованием классических методов компьютерного зрения, отображения результата в реальном времени и записи обработанного видео в MP4.

Проект написан на **C** и собирается в среде **MSYS2 UCRT64**.

---

## Возможности

* обнаружение доступных камер Windows через DirectShow;
* захват видео с камеры в реальном времени;
* поддержка формата камеры `YUYV422`;
* разрешение `640x480`;
* частота `30 FPS`;
* преобразование исходного изображения в `YUV420P`;
* построение адаптивного фонового изображения;
* обнаружение затемнённых областей относительно фона;
* анализ яркости канала `Y`;
* анализ цветовых компонентов `U/V`;
* адаптивные пороги `U/V`;
* морфологическая обработка маски:
  * открытие `3x3`;
  * закрытие `3x3`;
* фильтрация небольших областей по связанным компонентам;
* защита фона от обновления в областях обнаруженных теней;
* настройка чувствительности детектора в реальном времени;
* управление параметрами с помощью ползунков;
* точный ввод параметров с клавиатуры;
* визуальное выделение обнаруженных теней;
* отображение видео через SDL2;
* отображение панели управления;
* запись результата в `MP4`.

# Алгоритм обнаружения теней

Основная обработка реализована в:

```text
shadow_detector.c
```

Алгоритм является классическим методом компьютерного зрения и не использует нейронные сети.

Основная идея заключается в сравнении текущего кадра с адаптивной моделью фона.

Общая схема:

```text
             Камера
                │
                ▼
          Захват YUYV422
                │
                ▼
            FFmpeg
                │
                ▼
             YUV420P
                │
                ▼
       ┌───────────────────┐
       │ Построение фона   │
       └─────────┬─────────┘
                 │
                 ▼
        Сравнение с текущим
             кадром
                 │
                 ▼
          Анализ Y / U / V
                 │
                 ▼
          Первичная маска
                 │
                 ▼
            Opening 3x3
                 │
                 ▼
            Closing 3x3
                 │
                 ▼
       Connected Components
                 │
                 ▼
       Фильтрация областей
                 │
                 ▼
          Итоговая маска
                 │
                 ▼
          Обновление фона
```

# Построение фона

В начале работы программа собирает несколько кадров для построения фонового изображения.

Количество кадров по умолчанию:

```text
30
```

Фон хранится отдельно для каналов:

```text
Y
U
V
```

После накопления начального фона программа переходит к обычной обработке.

Модель фона является адаптивной и постепенно изменяется вместе со сценой.

---

# Обнаружение тени

Для каждого пикселя рассчитывается отношение текущей яркости к яркости фона:

```text
Y_ratio = Y_current / Y_background
```

Затем определяется степень затемнения:

```text
darkness = 1 - Y_ratio
```

Область считается кандидатом на тень, если она достаточно темнее фонового изображения.

Основной критерий основан на относительном изменении яркости, а не только на фиксированном значении `Y`.

Это позволяет алгоритму лучше работать при различных уровнях освещения.

Вместо простого условия:

```text
Y < constant
```

используется сравнение:

```text
Y_current / Y_background
```

Поэтому одна и та же тень может быть обнаружена как при относительно ярком, так и при относительно тёмном освещении.

---

# Анализ цветности

Одного изменения яркости недостаточно, поскольку затемнение объекта или изменение освещения может быть ошибочно принято за тень.

Поэтому дополнительно анализируются:

```text
U
V
```

Компоненты текущего кадра сравниваются с компонентами фонового изображения.

Используются отдельные пороги:

```text
max_u_diff
max_v_diff
```

Чем меньше эти значения, тем строже контролируется изменение цвета.

Также применяется адаптивная корректировка порогов в зависимости от степени затемнения.

Общая идея:

```text
adaptive_max_u =
    max_u_diff +
    darkness * uv_adaptive_factor * 255

adaptive_max_v =
    max_v_diff +
    darkness * uv_adaptive_factor * 255
```

Для более глубоких теней допускается несколько большее изменение цветовых компонент.

# Морфологическая обработка

После определения первичной маски выполняются две морфологические операции:

1. Opening;
2. Closing.

Обе операции используют структурирующий элемент:

```text
3x3
```

---

## Opening

Последовательность:

```text
Erosion
   ↓
Dilation
```

Открытие используется для удаления:

* небольших шумовых областей;
* одиночных пикселей;
* мелких артефактов.

---

## Closing

Последовательность:

```text
Dilation
   ↓
Erosion
```

Закрытие используется для:

* заполнения небольших разрывов;
* объединения близких областей;
* улучшения формы обнаруженной тени.

Размер структурирующего элемента:

```text
3x3
```

---

# Связанные компоненты

После морфологической обработки выполняется поиск связанных областей.

Используется связность:

```text
4-connected
```

Схематично:

```text
    X
    │
X ─ P ─ X
    │
    X
```

Для каждой области определяется её площадь.

Слишком маленькие области удаляются как шум.

Минимальная площадь задаётся параметром:

```text
min_shadow_area
```

Например:

```text
200
```

означает, что области менее 200 пикселей будут удалены.

---

# Адаптивное обновление фона

Фоновое изображение не остаётся неизменным.

Для каждого пикселя используется экспоненциальное обновление:

```text
background =
    background * (1 - alpha) +
    current * alpha
```

По умолчанию:

```text
alpha = 0.01
```

Это позволяет фону медленно адаптироваться к изменениям сцены.

Малое значение `alpha`:

```text
0.001
```

делает адаптацию медленной.

Большое значение:

```text
0.05
0.10
```

позволяет быстрее адаптироваться к изменениям.

---

# Защита фона от теней

Очень важная часть алгоритма — фон не должен обновляться на участках, которые в текущем кадре определены как тень.

Поэтому при обновлении используется логика:

```text
если pixel принадлежит тени
    фон НЕ обновляется
иначе
    фон обновляется
```

Это предотвращает постепенное «впитывание» тени в фон.

Без такой защиты неподвижная тень через некоторое время могла бы стать частью фоновой модели и перестать обнаруживаться.

# Основные параметры

Параметры детектора могут изменяться непосредственно во время работы программы через панель управления.

Основные параметры:

```text
MIN_Y_SHADOW
MAX_Y_SHADOW
MAX_U
MAX_V
MIN_SHADOW_AREA
BACKGROUND_ALPHA
```

Значения по умолчанию:

```c
#define MIN_Y_SHADOW       0.25f
#define MAX_Y_SHADOW       0.75f
#define MAX_U              12
#define MAX_V              12
#define MIN_SHADOW_AREA    200
#define BACKGROUND_ALPHA   0.01f
```

---

## MIN_Y_SHADOW

Минимальная степень затемнения, необходимая для обнаружения тени.

Увеличение значения:

```text
меньше ложных срабатываний
```

но слишком большое значение может привести к пропуску слабых теней.

Если тени плохо обнаруживаются:

```text
MIN_Y_SHADOW ↓
```

Если слишком много ложных срабатываний:

```text
MIN_Y_SHADOW ↑
```

---

## MAX_Y_SHADOW

Максимальная допустимая степень затемнения.

Параметр позволяет ограничить слишком тёмные области, которые скорее являются объектами, чем тенями.

Если тёмные объекты часто определяются как тени:

```text
MAX_Y_SHADOW ↓
```

---

## MAX_U

Допустимое изменение компоненты `U`.

Меньшее значение:

```text
строгая проверка цвета
```

Большее значение:

```text
больше допустимых изменений цвета
```

Если реальные тени не обнаруживаются из-за изменения цветности:

```text
MAX_U ↑
```

Если возникает слишком много ложных срабатываний:

```text
MAX_U ↓
```

---

## MAX_V

Аналогичный параметр для компоненты `V`.

Меньшее значение делает проверку цветности более строгой.

Большее значение позволяет детектору принимать более сильные изменения цветового компонента.

---

## MIN_SHADOW_AREA

Минимальный размер области, которая считается настоящей тенью.

Например:

```text
200
```

означает, что области менее 200 пикселей удаляются.

Если небольшие тени не обнаруживаются:

```text
MIN_SHADOW_AREA ↓
```

Если появляется много мелкого шума:

```text
MIN_SHADOW_AREA ↑
```

---

## BACKGROUND_ALPHA

Скорость адаптации фоновой модели.

Значение:

```text
0.01
```

означает медленное обновление.

Большое значение:

```text
0.05
0.10
```

позволяет быстрее адаптироваться к изменениям сцены.

Однако слишком большое значение повышает вероятность того, что объекты или тени будут постепенно поглощаться моделью фона.

Если после изменения освещения долго остаются ложные срабатывания:

```text
BACKGROUND_ALPHA ↑
```

Если тень слишком быстро исчезает:

```text
BACKGROUND_ALPHA ↓
```

# Панель управления

Программа содержит интерактивную панель управления справа от изображения.

Панель позволяет изменять основные параметры без остановки программы.

Поддерживаются:

* ползунки;
* числовые значения;
* ввод значения с клавиатуры;
* изменение параметров мышью;
* колесо мыши;
* подсветка активного параметра;
* текстовый курсор;
* подсказки.

---

# Управление

| Действие | Результат |
|---|---|
| ЛКМ по треку ползунка | Установить или изменить значение |
| ЛКМ по числовому полю | Включить режим ввода |
| Ввод цифр | Редактирование значения |
| Ввод `.` | Ввод дробного значения |
| Ввод `-` | Ввод отрицательного значения |
| `Enter` | Применить значение |
| `Esc` | Отменить редактирование |
| `Backspace` | Удалить последний символ |
| Колесо мыши над ползунком | Точная подстройка значения |
| `Tab` | Показать / скрыть панель |
| `R` | Сбросить фоновое изображение |
| `Q` | Завершить программу |
| `Esc` вне режима редактирования | Завершить программу |

# Сброс фоновой модели

Клавиша:

```text
R
```

используется для повторного построения фонового изображения.

Это особенно полезно, если:

1. программа уже построила фон;
2. изменилась сцена;
3. камера была перемещена;
4. изменилось положение объектов;
5. изменилось освещение.

После нажатия `R` текущая модель фона сбрасывается и строится заново.

# Запуск

Запуск выполняется командой:

```bash
./camera_yuv.exe
```

После запуска программа:

1. обнаруживает доступные камеры;
2. выводит список устройств;
3. позволяет выбрать камеру;
4. открывает видеопоток;
5. получает кадры `YUYV422`;
6. преобразует их в `YUV420P`;
7. строит первоначальный фон;
8. запускает обнаружение теней;
9. отображает видео;
10. отображает панель управления;
11. выделяет найденные тени;
12. записывает обработанный поток в MP4.

```text
30 FPS
```

каждый кадр содержит:

```text
640 × 480 = 307200
```

пикселей.

Основные операции выполняются непосредственно на CPU:

* сравнение `Y`;
* сравнение `U/V`;
* формирование маски;
* морфологическая обработка;
* поиск связанных компонентов;
* фильтрация областей;
* обновление фоновой модели.

Алгоритм не требует GPU и не использует нейронные сети.

# Типичные проблемы

## Камера не обнаруживается

Проверить список устройств:

```bash
ffmpeg -list_devices true -f dshow -i dummy
```

Если камеры нет в списке, необходимо проверить:

* подключение USB;
* драйвер камеры;
* доступ камеры в Windows;
* не используется ли камера другой программой.

---

## Проверка камеры через FFmpeg

Выполнить:

```bash
ffmpeg -f dshow \
-video_size 640x480 \
-framerate 30 \
-pixel_format yuyv422 \
-i video="Fifine K420" \
-t 5 \
test_camera.mkv
```

Если камера называется иначе, заменить:

```text
Fifine K420
```

на фактическое имя устройства.

---

## Ошибка `avcodec-*.dll was not found`

Если при запуске появляется сообщение:

```text
avcodec-*.dll was not found
```

это означает, что необходимые DLL FFmpeg отсутствуют или не находятся в `PATH`.

Проверить зависимости можно:

```bash
ldd camera_yuv.exe
```

Особенно важны:

```text
avcodec-*.dll
avformat-*.dll
avdevice-*.dll
avutil-*.dll
swscale-*.dll
```

Также могут потребоваться:

```text
SDL2.dll
SDL2_ttf.dll
```

и runtime-библиотеки MSYS2/UCRT64:

```text
libgcc_s_seh-1.dll
libwinpthread-1.dll
libstdc++-6.dll
```

---

## Тени не обнаруживаются

Попробуйте изменить параметры:

```text
MIN_Y_SHADOW ↓
MAX_Y_SHADOW ↑
MIN_SHADOW_AREA ↓
```

Также рекомендуется проверить:

* наличие достаточного контраста между тенью и фоном;
* корректность освещения;
* отсутствие сильного шума;
* правильность построения фоновой модели.

---

## Слишком много ложных срабатываний

Попробуйте:

```text
MIN_Y_SHADOW ↑
MAX_U ↓
MAX_V ↓
MIN_SHADOW_AREA ↑
```

---

## После смены освещения остаются ложные тени

Нажмите:

```text
R
```

для повторного построения фоновой модели.

Если проблема возникает постоянно, можно увеличить:

```text
BACKGROUND_ALPHA
```

Однако слишком большое значение может привести к слишком быстрой адаптации фона.

# Ограничения алгоритма

Алгоритм предназначен для классического обнаружения теней и имеет ограничения.

На результат могут влиять:

* резкое изменение освещения;
* очень тёмные объекты;
* объекты, имеющие цвет, похожий на тень;
* резкое движение камеры;
* изменение положения камеры;
* блики;
* шум камеры;
* большие изменения сцены;
* слишком медленное обновление фона;
* слишком быстрое обновление фона.

Алгоритм не выполняет семантическое распознавание объектов.

То есть он определяет **область, похожую на тень**, а не устанавливает с помощью нейронной сети, что это действительно тень конкретного объекта.
